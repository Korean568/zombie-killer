# 폐교 좀비 킬러

폐교를 배경으로 한 1인칭 3D 웨이브 생존 슈팅 게임. 브라우저에서 바로 돌아가고, 외부 에셋(이미지·음원) 파일이 하나도 없습니다.

**플레이:** https://korean568.github.io/fps-zombie-killer/

## 조작

| 키 | 동작 |
|---|---|
| `W` `A` `S` `D` | 이동 |
| `Shift` | 질주 (스태미나 소모) |
| `Space` | 점프 |
| `Ctrl` / `C` | 앉기 (명중률 상승) |
| 좌클릭 | 발사 |
| `R` | 재장전 |
| `1` `2` `3` / 휠 | 무기 교체 |
| `F` | 손전등 |
| `ESC` | 일시정지 |

## 내용

- **맵** — 중앙 복도, 교실 8개, 체육관 아레나. 사물함·책상·칠판·깨진 창문·형광등 깜빡임
- **무기 3종** — 권총(무한 탄약), 산탄총(9펠릿), 소총(자동). 웨이브 2·4에 해금
- **좀비 3종** — 일반 / 달리는 좀비 / 거대 좀비. 웨이브마다 체력·속도·피해량이 상승
- **경로 탐색** — 플레이어 위치에서 BFS 플로우 필드를 만들어 문을 통과해 추격. 시야가 트이면 직선 추격으로 전환
- **헤드샷** 판정 (권총 기준 2.85배)

## 기술

외부 라이브러리는 three.js 하나뿐입니다.

- **텍스처** — 콘크리트·장판·칠판·사물함·혈흔 전부 `<canvas>`로 런타임 생성
- **사운드** — WebAudio 오실레이터/노이즈로 총성·신음·발소리를 합성
- **렌더링** — 벽/소품은 `InstancedMesh`, 조명은 가장 가까운 형광등에만 실제 광원을 붙이는 풀 방식
- **뷰모델** — 별도 씬/카메라로 겹쳐 그려서 벽 관통과 월드 조명 간섭을 차단
- **충돌** — 격자 기반 원-AABB 판정, 사격은 DDA 격자 레이캐스트 + 구/캡슐 히트박스

## 실행

`index.html`을 브라우저로 열면 끝입니다. `lib/three.min.js`가 동봉돼 있어 인터넷 없이도 동작합니다.

로컬 서버로 띄우려면:

```bash
python -m http.server 8000
```

## 알려진 제한

- 소품(책상·사물함·농구 골대)에는 충돌 판정이 없어 통과됩니다.
- 데스크톱 전용입니다. 마우스 포인터 잠금과 키보드를 사용합니다.
